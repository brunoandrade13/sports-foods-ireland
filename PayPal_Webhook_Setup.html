1️⃣ Criar webhook no PayPal dashboard

URL do webhook (copiar esse valor):

Passos:

  1. Abrir developer.paypal.com/dashboard/applications/live e logar na sua conta.
  2. Selecionar o app live que você já usa pro checkout da SFI (o mesmo que gerou as PAYPAL_CLIENT_ID / _SECRET).
  3. Rolar até a seção "Webhooks" (geralmente no fim da página do app).
  4. Clicar em "Add Webhook".
  5. Em Webhook URL, colar a URL acima.
  6. Em Event types, selecionar:
    • ✓ PAYMENT.CAPTURE.COMPLETED

    (Você pode adicionar outros tipos sem impacto — a função já faz early-return pra eventos não processados.)

  7. Clicar em Save.
  8. O PayPal vai mostrar um Webhook ID (algo como 1YH04408XS...). Copiar esse valor.

2️⃣ (Opcional) Setar PAYPAL_WEBHOOK_ID no Supabase

Este passo é opcional. A função já funciona 100% sem ele — a verificação por API lookup é robusta. Mas setar o secret é uma otimização (evita 1 chamada extra ao PayPal por evento).
  1. Abrir Supabase → Settings → Edge Functions → Secrets.
  2. Clicar em "Add new secret".
  3. Name: PAYPAL_WEBHOOK_ID
  4. Value: (o Webhook ID do passo 1)
  5. Save.

📈 Depois que estiver rodando — como monitorar

Ver webhooks processados (DB):

SELECT event_id, event_type, gateway, processed_at
FROM processed_webhook_events
WHERE gateway = 'paypal'
ORDER BY processed_at DESC LIMIT 20;

Ver orphans recuperados (orders criadas pelo webhook):

SELECT order_number, customer_email, total, notes, created_at
FROM orders
WHERE notes LIKE '%orphan PayPal capture%'
ORDER BY created_at DESC;

Ver pending_paypal_orders não processados (clientes que abriram checkout mas não fecharam):

SELECT paypal_order_id, email, total, created_at, expires_at
FROM pending_paypal_orders
WHERE processed = false
  AND expires_at > NOW()
ORDER BY created_at DESC;

Alertas por email:

Quando um orphan é recuperado, você recebe email automático em info@sportsfoodsireland.ie com:

  • 🔄 Subject "PayPal Orphan Recovered: SFI-XXXXX"
  • Detalhes da order recuperada
  • Capture ID + link pra PayPal

Quando um capture chega sem pending cart correspondente (caso crítico — cliente pagou mas nem salvamos o carrinho):

  • ⚠️ Subject "PayPal Orphan Capture: [paypal_order_id]"
  • Precisa criar a order manualmente no admin
